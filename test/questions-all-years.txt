New total = 7 × 19 = 133
Age = 160 − 133 = 27

 STAGE 2 — HIDDEN BUG[2]
Q3. Hidden Array Bug — 10 Marks
The program is intended to find the second largest distinct element.

#include <stdio.h>
#include <limits.h>
int main() {

    int arr[] = {10, 25, 8, 30, 15};
    int n = 5;

    int largest = arr[0];
    int second = arr[0];

    for(int i = 1; i < n; i++) {

        if(arr[i] > largest) {
            second = largest;
            largest = arr[i];
        }
        else if(arr[i] > second) {
            second = arr[i];
        }
    }

    printf("%d", second);

    return 0;
}
For:
10 25 8 30 15
the program gives:
25
But test it with:
30 30 20 15 10
It gives an incorrect result.
Task
Find the hidden bug and modify the program so that it correctly finds the second largest distinct element.
Expected issue
The condition must ensure that arr[i] is not equal to largest.
A suitable correction is:
else if(arr[i] > second && arr[i] != largest)
Students should also initialize second appropriately rather than assuming arr[0] is a valid second-largest candidate.



Q4. Hidden String Bug — 10 Marks

    char str2[] = "code";

    for(int i = 0; str1[i] != '\0'; i++) {

            same = 0;
            break;
        }

    if(same)
        printf("Same");

}
The programmer wants the comparison to be case-insensitive.

Code
code
CODE
cOdE
should all be considered equal.

Expected approach

from <ctype.h>.

Q5. Final Boss — Debug the Array Rotation 
The following program is intended to rotate an array to the right by k positions.
Example:
Array:  1 2 3 4 5
k = 2
Expected:
4 5 1 2 3
But the program contains a logical error.

#include <stdio.h>
int main() {

    int arr[] = {1, 2, 3, 4, 5};
    int n = 5;
    int k = 2;

    for(int r = 0; r < k; r++) {

        int last = arr[n - 1];

        for(int i = n - 1; i > 0; i--) {
            arr[i] = arr[i - 1];
        }

        arr[0] = arr[n - 1];
    }

    for(int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
Task
Identify the bug and correct the program so that it produces:
4 5 1 2 3
 Hidden issue
The last element is saved in:
int last = arr[n - 1];
but then the code incorrectly does:
arr[0] = arr[n - 1];
At that point arr[n-1] has already been overwritten.
Correct line:
arr[0] = last;
Corrected portion:
for(int i = n - 1; i > 0; i--) {
    arr[i] = arr[i - 1];
}

arr[0] = last;
